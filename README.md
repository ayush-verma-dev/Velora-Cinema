# 🎬 Velora Cinema

> A modern full-stack movie ticket booking platform built with **React, Node.js, Express, MongoDB, and Tailwind CSS**.

![React](https://img.shields.io/badge/React-19-blue?logo=react)
![Node.js](https://img.shields.io/badge/Node.js-Express-green?logo=node.js)
![MongoDB](https://img.shields.io/badge/MongoDB-Database-green?logo=mongodb)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-CSS-38BDF8?logo=tailwindcss)
![JWT](https://img.shields.io/badge/Auth-JWT-yellow)

Velora Cinema provides a premium cinema booking experience with an elegant UI, movie browsing, theater selection, seat booking, secure authentication, and online payments.

- Booking summary
